# お問い合わせフォーム（Google Apps Script）セットアップ手順

`contact.html` のお問い合わせフォームを実際に動かすには、Googleスプレッドシート側の準備が必要です。一度だけ行えば、以降は自動で動きます。

---

## 1. Googleスプレッドシートを作成する

1. [Googleスプレッドシート](https://sheets.google.com/)を開き、新しい空白のスプレッドシートを作成する
2. シート名（下部のタブ）を `お問い合わせ` に変更する（タブを右クリック → 名前を変更）
3. 1行目に、以下の見出しをA列から順に入力する（admin用の見出しなので文言は自由に調整可。列の**順序**だけは変えないこと）

   ```
   受付番号 | 送信日時 | お問い合わせ種別 | 初回自己申告 | 自動判定 | 過去問い合わせ回数 | お名前 | メールアドレス | 団体名・所属 | 団体URL・SNS | 対象イベント名 | 対象ページURL | 希望掲載日 | 申込URL・詳細URL | 予算感 | お問い合わせ内容 | 対応状況 | 優先度 | 担当者 | 対応メモ | 最終更新日
   ```

4. ブラウザのアドレスバーに表示されているURLから、スプレッドシートIDをコピーしておく

   ```
   https://docs.google.com/spreadsheets/d/【ここがスプレッドシートID】/edit
   ```

## 2. Apps Scriptを開く

1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を選択する
2. エディタが新しいタブで開く

## 3. `gas/contactForm.gs` のコードを貼り付ける

1. エディタ内の `コード.gs`（または `Code.gs`）の中身を全て削除する
2. このリポジトリの [gas/contactForm.gs](../gas/contactForm.gs) の内容を全てコピーし、貼り付ける
3. 上部の保存アイコン（💾）またはCtrl+Sで保存する

## 4. スプレッドシートIDを設定する

貼り付けたコードの上部にある以下の行を、手順1でコピーしたIDに書き換える。

```javascript
const SPREADSHEET_ID = 'ここにスプレッドシートIDを入れる';
```

シート名を `お問い合わせ` 以外にした場合は、同じく上部の `SHEET_NAME` も変更する。

## 5. 管理者メールアドレスを設定する

同じく上部にある以下の行を、通知を受け取りたいメールアドレスに書き換える。

```javascript
const ADMIN_EMAIL = 'ここに管理者メールアドレスを入れる';
```

## 6. Webアプリとしてデプロイする

1. エディタ右上の「デプロイ」→「新しいデプロイ」をクリック
2. 「種類の選択」（歯車アイコン）→「ウェブアプリ」を選ぶ
3. 設定項目を以下にする
   - **実行ユーザー**: 自分（あなたのGoogleアカウント）
   - **アクセスできるユーザー**: 全員
   - ※「全員」にしないと、サイト訪問者（Googleにログインしていない人）からの送信が拒否されます
4. 「デプロイ」をクリックする
5. 初回は「承認が必要です」という画面が出るので、自分のGoogleアカウントを選び、「詳細」→「（プロジェクト名）に移動」→「許可」と進む
6. デプロイ完了後に表示される「ウェブアプリのURL」（`https://script.google.com/macros/s/.../exec` の形式）をコピーする

> コードを修正した場合は、上書き保存だけでは反映されません。「デプロイ」→「デプロイを管理」→ 該当のデプロイの編集（鉛筆アイコン）→ バージョンを「新バージョン」にして「デプロイ」し直してください。

## 7. WebアプリURLをフロントエンド側に設定する

[contact.js](../contact.js) の先頭にある以下の行を、手順6でコピーしたURLに書き換える。

```javascript
const CONTACT_GAS_URL = 'https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec';
```

## 8. テスト送信の確認方法

1. `contact.html` をブラウザで開き（ローカルサーバー経由、または実際に公開したサイトで）、テスト用の内容を入力して送信する
2. 「お問い合わせを受け付けました」というメッセージが表示されることを確認する
3. スプレッドシートに1行追加されていることを確認する
4. 入力したメールアドレス宛に確認メールが届いていることを確認する（迷惑メールフォルダも確認）
5. `ADMIN_EMAIL` 宛に通知メールが届いていることを確認する
6. もう一度テスト送信し、受付番号が連番（`-002`など）で発行されること、「自動判定」が「複数回目」になることを確認する

## 9. よくあるエラーと対処法

| 症状 | 原因・対処法 |
|---|---|
| 送信しても何も起こらない／コンソールにCORSエラーが出る | デプロイ設定の「アクセスできるユーザー」が「全員」になっていない可能性。手順6を確認 |
| 「送信に失敗しました」と表示される | `CONTACT_GAS_URL` が正しいURLになっているか確認。コード修正後に再デプロイ（新バージョン）し忘れていないか確認 |
| スプレッドシートに行が追加されない | `SPREADSHEET_ID` ・ `SHEET_NAME` が正しいか確認。シート名の前後に余分なスペースが入っていないか確認 |
| メールが届かない | 迷惑メールフォルダを確認。Apps Scriptの実行ログ（エディタ左の時計アイコン「実行数」）でエラーが出ていないか確認。個人のGoogleアカウントは1日に送信できるメール数に上限があるため、テストを何度も繰り返すと上限に達することがある |
| 「このアプリは確認されていません」という警告が出る | 自分が作成したスクリプトなので問題ない。「詳細」→「（プロジェクト名）に移動」→「許可」と進めば使用できる |
| 受付番号が重複する | `LockService` が正しく動いているか確認。通常は自動で排他制御されるため発生しない想定 |
